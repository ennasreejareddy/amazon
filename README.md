# Amazon Clone 🛒

A front-end clone of the Amazon homepage built using **HTML and CSS**. This project recreates the look and layout of an Amazon-style shopping website, including a navigation bar, search section, hero banner, product category cards, and footer.

## 🌐 Live Demo

**[View Amazon Clone](https://ennasreejareddy.github.io/amazon/)**

## 📂 GitHub Repository

**[View Source Code](https://github.com/ennasreejareddy/amazon)**

## ✨ Features

- **Navigation Bar:** Amazon-style logo, delivery location, search area, account section, returns, and cart.
- **Category Navigation:** A secondary navigation panel for browsing categories.
- **Hero Banner:** A large promotional banner on the homepage.
- **Product Categories:** Eight shopping category cards with images.
- **Footer Section:** A multi-section footer inspired by Amazon's layout.
- **Responsive Styling:** Flexbox-based layout with CSS styling.
- **Icons:** Font Awesome icons for a familiar shopping interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Font Awesome
- Git and GitHub
- GitHub Pages

## 🚀 Run the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ennasreejareddy/amazon.git
   ```

2. Open the project folder:

   ```bash
   cd amazon
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## 🎯 Project Objective

The objective of this project is to practice front-end web development by recreating a familiar e-commerce homepage and applying HTML structure, CSS styling, layouts, images, and icons.

## 📚 Learning Outcomes

- Structuring webpages with HTML.
- Styling elements using CSS.
- Building layouts using Flexbox.
- Organizing and linking image assets.
- Publishing a static website with GitHub Pages.
- Managing project files with Git and GitHub.
